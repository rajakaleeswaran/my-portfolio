# My Portfolio

A personal developer portfolio built with **React** and **Vite** to showcase my projects, technical skills, and contact information.

## ✨ Highlights

- Responsive portfolio experience
- Developer introduction and skills section
- Project showcase
- Contact section
- Fast development workflow with Vite

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS

## 🚀 Getting Started

### Prerequisites

- Node.js installed
- npm installed

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open the local URL shown by Vite in your browser.

## 📁 Project Purpose

This project is part of my developer portfolio and demonstrates my ability to build and organize a modern frontend application using React.
